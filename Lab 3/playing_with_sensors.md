## Lab 3 Objectives

To help get comfortable with using the esp32 with a potentiometer and touch sensor. Teaching how to code and take inputs and outputs to and from the esp32.

## How to Assignment Was Completed and Contents 

Using Platform.IO and Windows Software

This markdown includes the location of the code for reading analog voltages off of the potentiometer found in the potentiometer.cpp (simply reading values off the potentiometer) and voltage.cpp (reading voltages of the potentiometer). It also includes the location of the code for the touch sensor that displays a message whether or not the sensor was touched and also blinks a light when touched.

All of these .cpp files are in the lab 3 folder, under src. To implement the code al lthat is needed is to connect an esp32 to a potentiometer or touch sensor with jumper wires and then upload the code to the esp32. Ensure that when running one of the four files, the other three are commented out.
